# TransFlow: About page

A single scroll-driven page that explains TransFlow. It opens with the TransFlow logo, then scrolls horizontally through the app's main steps and data notes.

## Run locally

```bash
npm install
npm run dev
```

Open the address that Vite prints. To preview the production build:

```bash
npm run build
npm run preview
```

## Deploy

The site is static. Deploy the `dist` folder to Cloudflare Pages:

```bash
npm run deploy
```
